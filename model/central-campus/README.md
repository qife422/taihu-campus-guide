# 中央校区 Blender 模型

本轮改为卫星影像与校方照片支持的局部细化模型，替代同名文件中的示意图体块。当前可审查外观与空间关系，但尚未达到测绘或校方验收状态。正式网页未接入本模型。

## 查看

- `central-campus.blend`：可编辑 Blender 场景，鸟瞰相机、材质及隐藏卫星参考。
- `central-campus.png`：局部总览。
- `central-campus-plan.png`：垂直俯视，便于叠加核对。
- `teach6-detail.png`：六号教学楼近景。
- `footprints.geojson`：通过影像导出范围转换的 WGS84 多边形。
- `footprints.json`：对应的影像像素轮廓和高度估计。
- `manifest.json`：来源、限制与 SHA-256。
- `validate.py`：不依赖额外 GIS 库的轮廓验证脚本；`validation.json` 保存当前校验结果。

## 地理定位

卫星来自 Esri World Imagery 的公开地图服务。导出时请求范围为经度 120.220–120.226、纬度 31.576–31.580，输出 1800 × 1400，投影 EPSG:3857。实际导出范围以 `references/satellite-export.json` 为准，不能直接假定与请求范围完全相同。

以中心纬度 31.578° 对 Web Mercator 长度做局部缩放，得到约 0.318 米/导出像素。这是输出像素间距，**不代表卫星原始分辨率或模型定位精度**。轮廓来自可见屋顶，尚未校正建筑倾斜位移、树木遮挡和屋檐外挑，因此 GeoJSON 不能标记为测量的建筑落地轮廓。影像拍摄日期未取得。

原校园示意图仅辅助判断区域与名称，未对示意图强行做全校控制点变换。卫星地理定位不需要把该示意图当作等比例总平面图。

## 复现与验收

使用 `/Applications/Blender.app/Contents/MacOS/Blender --background --python model/central-campus/build.py`。

当前验收范围：能打开场景、渲染清晰几何、图像与轮廓来源可追溯；不代表全校布局、建筑高度、名称或立面已经通过真实性验收。需要校方 CAD/正射航拍、六号楼各向照片及高度信息后完成校核。

## 容量边界

本目录生成物达到 100 MB 或 20 个文件时停止继续扩大并盘点，不自动清理。运行依赖与临时抓取保留在工作树外。此前同名渲染与场景已被本轮替换，其旧 manifest 不再是活动证据；本轮 manifest 仅记录本轮输出。

## 恢复后修正

六号楼原有 29 个柱对象中两处端点重复，修正为 27 个独立柱对象；建模脚本增加位置去重。总览相机范围调整为 485，俯视范围调整为 500，避免边缘裁切。10 个 GeoJSON 多边形外环统一逆时针，已校验闭合、自交、范围及影像像素→经纬度→像素往返误差。校验仅保证数据一致性，不能证明实地精度。
