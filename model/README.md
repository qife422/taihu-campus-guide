# 校园建模工作区

`central-campus/` 保留已展示中央样板，名称与输出不变。用户于 2026-09-07 授权根据照片和网上资料自主估算高度，并完成全校建模；`campus/` 是新增的全校范围场景，复用中央样板几何，不是其改名或备份。

扩展前只读盘点为 18 个文件、38.71 MiB。中央样板原有 100 MB / 20 文件边界继续有效，不在该目录累加全校产物。全校范围预算为 128 MiB / 25 文件；整个 model 工作区预算为 192 MiB / 50 文件。任一触发停止同类生成并盘点，不自动删除、移动或压缩现存文件。全校可再生输出相对建模源码与布局数据合计不得超过 1500 倍。临时下载、检查裁切与试渲染放在 /tmp/taihu-full，不视为正式证据。

估算高度是用户允许的建模参数；平面轮廓仍须有影像依据。来源、建模取值与确定程度随模型保存。GeoJSON 屋顶轮廓不是实测落地边界。
