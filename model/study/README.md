# 中央校区离线效果图

本目录是中央湖区三组建筑的 Blender 表现样板，主图 4000×3200。建筑位置和主体轮廓来自固定卫星影像与原中央场景，外观细节参考校方照片；高度、窗格与隐蔽部分仍为估算。尚未接入全校模型或替换网站中的 GLB，不属于测绘成果。

## 当前模型结构与表现

三组建筑分别保存在 `B06/B07/B08 Central detailed architecture` 父组下，构件可独立编辑。原屋顶和主体轮廓的保留构件与 `../central-campus/central-campus.blend` 做顶点、面索引、世界变换比对；B06 内部墙芯已在上一轮为窗带退距重建，不能称其与最初主体完全相同。

B07/B08 现在是本轮重建立面的独立构件，不再是未经修改的背景合并网格。外凸线脚与山墙为照片支持的解释性构造，不修改源轮廓文件。

材质使用程序化陶色接缝、屋面与铺装细节。玻璃使用整窗模块级细微变化，IOR 1.46 与少量透射；程序天空与斜向太阳强调窗框和柱廊深度。光照不代表实测日期。草地材质以固定卫星灰度作 12% 低强度调制，仍由矢量地块边界控制；不铺整张影像平面。未使用 AI 生图或外部植物资产。

树冠使用六种共享细叶网格，保留来源支持的 119 个树冠/树带布置点；每种网格 26000 个叶片面，树高与冠幅为估算。14 辆停车车辆、铺装细缝和前庭绿篱为表现性细节。

场景保存 `Central architectural birdseye` 主相机与 `B06 facade review` 检查相机。主图同时容纳三组建筑；道路在样板裁切边界处截断，不代表尽端道路。

## 输出与复现

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background -t 4 --python model/study/build.py -- --preview
/Applications/Blender.app/Contents/MacOS/Blender --background -t 4 --python model/study/build.py
```

Blender 5.2.1 LTS；脚本依赖 `/tmp/taihu-gis-deps` 中的 Shapely 2.1.2。预览写 `/tmp/taihu-study/campus.blend` 和 `campus.png`，1800×1440、20 采样。正式输出沿用本目录 `campus.blend` 与 `campus.png`，Cycles 56 采样、4000×3200 原生渲染，无插值放大。

`manifest.json` 保存输入/输出 SHA-256、校验脚本全文、保留构件比对结果、三组建筑取景边界及验收限制。图像由人工式目视检查确认可读性，几何校验只证明来源一致性，不证明实地精度。

## 容量与限制

本目录最多 6 文件 / 70 MiB；整个 model 最多 50 文件 / 192 MiB。沿用已有五个正式文件，临时预览和日志写入 /tmp；不新增备份、不删除历史。外部植物候选仅检查元数据，未下载或导入。

本目录保留中央三组建筑的独立精细样板；全校场景的接入与验收状态见 `../campus/README.md` 和其 manifest。中央样板自身通过 Blender/GIS 脚本完成，未使用 UI 或 AI 生图 skill。

为避免全校场景与中央样板互相依赖，构建脚本已移除未使用的全校模型载入步骤，仅依赖原始中央模型与固定参考资料。使用 `-- --scene-only` 可重建可编辑文件而不重渲图像。本次对 26987 个对象的几何、材质节点、世界变换、修改器及世界/渲染设置进行前后指纹比较，确认现有 4000×3200 图像所对应的视觉状态未改变；方法和结果写入 manifest。
