# 太湖校园导览 Demo

无锡太湖学院新生报到与校园导览交互原型。

项目名称沿用 **太湖校园导览 Demo**，GitHub 仓库为 [qife422/taihu-campus-guide](https://github.com/qife422/taihu-campus-guide)。这是 React、Leaflet 与 Three.js 前端，附带 Blender 模型、建模脚本、来源影像和地图制作证据，供新生和访客浏览校园。

## GitHub 备份与恢复

完整项目位于 `source` 分支；原 `main` 分支保留已有网页发布包。备份包括全部源码、原模型（含 `.blend`／`.blend1`／`.glb`）、影像、布局、网页资产、固定树冠纹理以及当前和历史制作记录。依赖、构建副本、浏览器缓存和 Python 字节码未上传，恢复时可重建。

```bash
git clone --branch source https://github.com/qife422/taihu-campus-guide.git
cd taihu-campus-guide
python3 scripts/verify_backup.py
npm ci
npm run dev
```

使用 Node.js 22.12 或更高的受支持版本。更详细的换电脑、下载 ZIP、模型恢复和再次备份步骤见 [恢复说明](恢复说明.md)。[backup-manifest.json](backup-manifest.json) 记录备份文件的大小和 SHA-256；已有模型和当前鸟瞰图片直接包含在仓库中，运行网站不需要先重新建模。

目前地图制作及整站仍未达到 [武汉理工大学示例网站](https://gis.whut.edu.cn/index.shtml) 的最终质量；楼体外观、高度、部分地点与路线具有原型或表现估算边界，不能当作实测导航。最新画面与验收以本页当前进度和 `public/assets/campus-atlas.json` 为准，下面的历史记录保留各自范围。

## 已展示功能

默认鸟瞰现已整合区域、用途分类、搜索、高亮、建筑及来源地点详情，并提供校园全景入口；卫星入口保留旧服务点、新生指引和路线演示，实体点位仍需统一核实，整体尚未达到参考网站。

- 校园及周边卫星地图浏览
- 地点搜索、分类与详情
- 新生报到步骤与路线演示（尚未核实真实导航路网）
- 校园真实 360° 全景及地点场景直达
- 桌面端与移动端响应式界面
